# Como contribuir com este mirror

Este repositório acompanha automaticamente
[`DBSeller/e-cidade`](https://github.com/DBSeller/e-cidade), mantido por
**DBSeller**.

## Alterações no código

Correções e funcionalidades relacionadas ao código sincronizado devem ser
propostas diretamente no repositório de origem:

- [`DBSeller/e-cidade`](https://github.com/DBSeller/e-cidade)

Isso evita que uma contribuição seja aplicada apenas ao mirror e se perca na
próxima sincronização.

## Alterações administrativas do mirror

Pull requests neste repositório podem ser usados para alterações na camada
administrativa mantida pela organização e-Cidade, como:

- identificação e documentação do mirror;
- orientações de contribuição;
- metadados comunitários;
- automações específicas da infraestrutura de mirror.

Se não estiver claro onde sua contribuição deve ser enviada, utilize o hub
comunitário em [`e-cidade/e-cidade`](https://github.com/e-cidade/e-cidade).
